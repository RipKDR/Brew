# Brew Assets Scaffold

This repository now includes a lightweight Unity-style scaffold for Week 1 kickoff.

Directory intent:

- `Scripts/Core` - board and gameplay core logic entry points.
- `Scripts/Data` - ScriptableObject-backed config containers.
- `Scripts/Input` - input and cluster selection logic.
- `Prefabs` - reusable board/UI objects created in Unity editor.
- `Art` - source and exported visual assets.
- `Audio` - music, SFX, and ambient tracks.
- `Data` - level and configuration assets.
- `Scenes` - Unity scenes (created in editor and tracked as `.unity` files).
- `Plugins` - third-party SDKs and packages.
- `Editor` - editor tooling scripts.

Note:

- Scene and prefab binaries should be authored from Unity Editor and committed after creation.
